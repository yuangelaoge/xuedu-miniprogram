# 微信审核样例入口（源码交付说明）

本变更仅提供源码、迁移文件和本地验证；未执行 005 迁移、未修改云端配置、未部署云函数或上传小程序。因此当前线上版本不能使用此入口。

入口位于小程序首页未登记卡片及“我的”页。审核人使用固定用户名和部署时提供的密码登录，服务端仍读取可信微信 OPENID；同一微信可以在管理员、组部长、普通成员和未入组申请人的独立合成资料之间切换；后者只是审核体验状态，不是新增的业务角色。每个微信获得一份独立的临时样例，审核操作不会写入原有 `xuedu_v2` 表、照片桶或真实成员资料。照片选择用于验证上传及授权流程，原图不会被保存，预览显示内置样例图；不要在样例中填真实个人资料。业务清空、初始化与旧接口在审核模式不可用。

部署前由维护者单独审查并执行 `server/migrations/005-review-sandbox.sql`。该迁移创建 `xuedu_review` 会话和登录尝试表，以及仅服务端可调用的 RPC；不修改原有业务表。审核会话限制为每微信一小时且不晚于配置的总截止时间，过期后拒绝读写；后续登录会清理已过期会话和旧尝试记录。每微信连续错误五次或全局错误三十次触发十五分钟限制。所有审核写入按会话版本原子比较，冲突提示刷新。

云函数启用前，需要在**服务端配置**中设置 `REVIEW_ENABLED=true`、`REVIEW_ACCESS_UNTIL`（带时区的 ISO 8601 截止时间）、`REVIEW_SESSION_KEY`（随机 32 字节的十六进制字符串）及 `REVIEW_PASSWORD_HASH`。在私有终端运行 `node scripts/hash-review-password.mjs`，交互输入密码，脚本只输出 scrypt 摘要；请勿把原密码、摘要、会话密钥写入仓库、命令参数、对话或日志。维护者仍需核对既有函数超时和云环境配置。需要停用时，把服务端 `REVIEW_ENABLED` 设为 `false` 并重新发布函数；可轮换 `REVIEW_SESSION_KEY` 作废现有审核会话。

独立验证建议：安装前检查迁移权限；部署后用真实微信依次切换三类业务角色和申请人体验，核对申请／人工审核／限时自动通过、课表、排班、记录、照片授权与提交，并验证另一个微信与普通成员无法读取本会话资料。此处本地测试通过不代表已完成真机或线上验收。

## 提审覆盖边界

本地测试已经走通样例的申请与人工审核、限时自动通过、课程与班级查询、下周排班生成及确认、成员上传照片后提交记录、照片访问权限、历史记录和 TXT／Excel 导出。图片预览现在先把内置样例图解析为微信本地文件路径；这只证明代码路径，仍须真机确认显示效果。

以下环节**不能宣称已供审核员完整体验**：

- 审核选图的原始内容不会写入云存储；提交后统一显示明显标记的示意图，因此无法验证真实签字照片的持久化、跨设备读取或云存储恢复。
- 首次安装建立首位管理员、业务清空和清空后的重建在审核模式禁用；这三项需要单独设计受控演示，避免审核员误认样例清空会影响真实数据，或因样例被重置而无法继续体验。
- 真实 PostgreSQL 迁移、微信开发者工具及手机端尚未执行验证。005 未上线前入口不可用。

提审资料应明确以上限制，不使用“所有功能均可体验”的描述。
