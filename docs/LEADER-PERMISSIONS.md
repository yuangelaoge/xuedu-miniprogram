## 实现与兼容

- 使用明确能力函数控制前端按钮与共享 handler；本地 demo 同步移除组部长的排班与 Excel 入口。真实云模式及审核体验均由 V2 gateway 校验角色。
- 完整 Excel 使用独立 `excelReport` 查询，仅管理员获准；导出前后 `reportCheck(format=xlsx)` 再检查管理员身份与版本。信息部干事继续仅获取 `summaryReport` 聚合数据。
- 组部长普通 `report`、TXT、统计及查看明细保留。取消系统导出不意味着禁止把已获准查看的数据自行整理；旧前端通用 report 查询无法辨别本机输出格式。后端部署后可阻止生成和确认，新导出入口也会拒绝组部长；正式版按钮需更新前端包并经过相应上传审核发布流程后才变化。
- `taskAdjust` 只生成草稿，所有 `planConfirm`（包括取消、补排、跳过）仅管理员执行，组部长不能通过调整路径使任务立即生效。
- 普通 page-load 与 006 单次数据库读取 RPC 保留组部长管理阅读范围；它们没有写入或专门导出路径。无需数据库迁移；保留既有加载优化、审核会话修复与信息部干事权限。
