## 已实现

- 提交及更正共用四组表单：考勤与课堂状态、请假与旷课名单、观察与反馈、签字照片。显示任务或记录保存的课程、班级、日期和听课成员快照。更正继续要求原因和版本号，服务端权限、24 小时窗口和人数规则保持不变。
- “标记缺失”仍提交 `-1`，不把空白当作零。“其余情况均为0”只填空白异常人数，不改应到、实到、已填值和缺失值。“无人旷课／无人请假”只填名单为“无”，不修改人数。草稿只恢复当前表单认识的文字字段；损坏的草稿结构不会阻止重新填写。
- 选择照片后显示上传中的缩略图；上传成功后加入本次照片列表。上传期间锁定移除及取消。表单照片与记录详情每次放大时均重新请求现有 `photoUrls` 接口，服务端拒绝时不使用旧链接继续预览。编辑历史照片仍受原记录权限约束，移除本次照片不会删除历史版本照片。
- 课程列表展示班级、教师、性质、节次和教室，支持按已加载资料的年级筛选及课程／班级／教师搜索，详情显示有效周次和课表人数。年级取班级资料，不从名称或 ID 推断。班级资料每页50条，由用户继续加载；缺资料时明确提示筛选尚不完整。
