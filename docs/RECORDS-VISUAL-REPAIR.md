# V2 记录页视觉回归修复（2026-09-23）

基线为主目录 `03ff285` 对应的前端源码，本次继续在独立分支 `codex/v2-frontend-repair` 实施。主目录的考评文档未跟踪文件保持原状。只修改小程序模板、样式、页面状态和回归测试；不修改业务接口、云函数或数据库，也没有上传小程序或操作线上资料。

手机截图和 365px 微信模拟器复现出相同问题：记录页在列表前放置四个按钮，`.v2-actions` 允许换行，而原生 `button` 的默认宽度约 184px、`flex-basis` 为 `auto`。容器约 335px，两个按钮放不下，四个按钮依次占行且只覆盖左半宽。安排页的三个操作按钮也有同样问题。旧版 `f650f29` 记录页把进度、页签和记录/统计作为主体，导出放在内容后，两个导出按钮并排。

本轮把记录页学期选择压成一行；进度与跳过提示留在周次下方；页签直接切换记录和周统计，删除重复的“查看本周统计”按钮；导出区移到内容后，名单 TXT 与汇总 Excel 各占半行，复制名单变为轻量入口。文件保存入口仍可打开/分享。空周、跳过周、个人无记录及未启用学期各有独立提示。即使配置了年级，零记录周也不显示“观测 0 次”的年级行；有记录但人数指标缺失时，原统计口径不变。记录列表改用独立卡片，姓名、已提交标记和日期同列展示，课程、班级、节次取记录快照，详情为轻量入口；管理和课程卡片仍沿用原布局。切换周次后重新读取周统计，避免旧周数字留在新周页。

通用 `.v2-actions` 按钮明确设置弹性基准、最小宽度和零边距，长文字可换行。该规则覆盖安排、管理和表单等共用操作区；小型管理按钮维持紧凑尺寸。记录页双列导出区使用单独规则。没有调整按钮对应的操作、权限或数据查询范围，记录列表继续分页。
