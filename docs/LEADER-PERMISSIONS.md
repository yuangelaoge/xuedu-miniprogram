## 实现与兼容

- `canAdjustTasks`、`canExportNames` 均只准 admin；前端相关按钮、共享 handler 和 taskAdjust 表单提交同步限制。组部长不显示排班工作台和汇总导出空卡片，不删除统计页、首页“查看汇总”、提交状态和自身听课入口。
- 云端 `taskAdjust`（补排、转派、取消）与 `planConfirm` 均仅管理员。移除普通成员仍按既有规则自动取消该成员未完成任务，这是保留的成员管理行为，不开放任意调整。
- 完整 Excel 用 `excelReport`；名单 TXT/复制改用独立 `namesReport`，都仅管理员。通用 report 显式携带 format=xlsx/txt/copy 也拒绝非管理员。导出/复制前，以及保存文件后，用 reportCheck(format=xlsx 或 txt) 检查权限与版本。
- 普通 report、无导出格式的 reportCheck 保留明细/统计读取。信息部干事仍仅使用 summaryReport 获得聚合导出资料；其 taskAdjust、namesReport、excelReport 均被拒绝。
- 取消系统输出不承诺阻止使用者自行整理已获准查看的数据；旧前端可能用通用 report 在本机生成文件，因此需要同步更新前端和后端。
- cloud 与审核体验共用 V2 gateway 限制；本地 demo 的 TXT、复制、Excel handler 与入口同步收紧。006 单次读取 RPC 与普通 page-load 保留既有阅读范围，没有写入或专门导出路径，无需 SQL 迁移。
- 保留刷新失败/审核到期修复：读取失败即收起生成、确认、调整和名单/Excel权限，相关 handler 拒绝操作，成功读回后按角色恢复。审核提示显示当前体验角色及查看/切换/退出入口，不自动清除用户草稿。

## 验证与范围

角色回归覆盖后端拒绝 leader 全部草稿/确认/名单输出，补排/转派/取消拒绝后不写入；管理员仍可调整确认、导出与复制；保留 leader 记录/照片/统计及审核能力；审核样例 officer 仅聚合导出，不获得调整或原始名单。前端直接调用 handler 和伪造 taskAdjust 表单同样被阻止。本地 demo 单独验证导出/复制边界。

官方 wcc 编译渲染脚本覆盖异步冷启动、角色切换、正式任务卡，断言 leader 没有调整/名单输出按钮和空卡片，首页“查看汇总”仍存在；admin/officer 各自按钮保持。详情见 scripts/check-leader-rendering.mjs。

本轮实际验证：198 项自动化测试通过，19 项需要独立数据库的测试在常规运行中跳过；类型检查、18 个 WXML 编译、V2 云函数构建及异步页面/编译渲染脚本通过。本轮未修改 SQL，未重跑独立数据库套件；此前 9 项 page RPC 验证作为已有基线，不计入本轮新运行。无线上业务写入、真机新版验收或数据库迁移。
