# iPhone 照片传输修复（2026-10-21）

## 已确认与实测

用户要求保留单张 **5MiB 原图**选择上限，修复小照片仍被微信拒绝的问题；不能把310KB照片解释为超过2MB，也不能把本地通过当作线上验收。

原故障 iPhone（iOS 27.0.1、微信8.0.79、基础库3.17.4）通过官方远程调试，只调用 `deploymentStatus` 并附带合成字符串：

| 完整 JSON 字节数 | 实测结果 |
| --- | --- |
| 81996、163916、194636 | 成功，约560–821ms |
| 204876、215116、245836、422988 | `data exceed max size`，约8–16ms即失败 |

这些数值限定于该设备与调用链路，不是微信所有设备的统一限额。此前“图片310KB、请求413KB”的错误与实测一致；384KiB图片／600KiB请求预算不能解决此故障。选择照片时仅上传单张内容，正式提交只带照片编号，不是全部历史照片相加。

官方依据：[callFunction 大数据字段说明](https://developers.weixin.qq.com/miniprogram/dev/wxcloud/reference-sdk-api/functions/Cloud.callFunction.html)、[wx.cloud.CDN](https://developers.weixin.qq.com/miniprogram/dev/wxcloud/reference-sdk-api/utils/Cloud.CDN.html)。

## 当前本地实现

- 前端通过 `wx.cloud.CDN({type:'filePath',filePath})` 发送文件，新增 `photoFile` 操作只带文件引用、大小及任务标识；JSON预算16KiB，不再包含整张Base64。
- 原图上限仍为5MiB。384KiB压缩目标继续用于适配现有私有桶525000字节的限制，不再声称是微信请求安全阈值；未修改线上桶限制。压缩后可预览核对签字。
- 服务端先校验可信微信身份、轮次、学期、任务归属及24小时修改期限，再下载文件，校验实际字节数和JPEG/PNG标识，然后写入既有私有照片库；PNG保留正确扩展名和内容类型。
- 接收仅允许实测SDK返回的 `vweixinf.tc.qq.com/301/`，拒绝其他域名、路径、凭据、非默认端口及跳转；限制读取大小和时间。新接口复用现有照片读写事务，无数据库迁移。
- **传输限制：** 实测微信返回HTTP临时地址，该主机直接改HTTPS会出现证书域名不匹配。本实现保留SDK返回的协议，不关闭证书校验、不猜测替代域名。因此该临时下载段不能声称HTTPS加密；临时链接不存入业务记录或日志，正式照片仍在私有桶中，预览继续使用经鉴权签发的HTTPS短时链接。临时CDN副本的保留期由微信管理，本项目未验证其具体时长。
- 上传失败不登记成功结果。当前进程内重新选择同一张失败照片可复用请求编号，恢复丢失的成功回包；私有对象路径仍按实际内容去重。跨进程重新选择不保证复用同一登记编号。
- 旧 `photo` 后端入口保留。新前端遇到旧后端明确提示更新，不退回已知有问题的大JSON。审核体验仍使用内置图片，不向CDN发送选择的真实照片。
