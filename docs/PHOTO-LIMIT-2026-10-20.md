# 签字照片：1 张、单张 2MB

发布更新：本功能已从 f54d967 推送私有 main、部署既有后端并上传微信开发版 1.3.3。以下“未部署或上传”为开发交付时状态，最新证据和验收边界见 [1.3.3 发布记录](RELEASE-1.3.3.md)。

2026-10-20 用户要求将原来 500KB、最多 3 张改为 2MB、1 张。本次新增或替换照片限制为 1 张，单张最多 2×1024×1024 字节。

- 当前云端表单、demo 选择入口和提示同步。2MB 内不额外触发应用压缩；超出时沿用一次压缩，仍超出则提示裁剪。
- V2 网关和私有存储适配器同步校验真实字节大小；Base64 精确扣除填充，恰好 2MB 允许。仅 photo 请求上限相应扩大，普通请求上限不变。审核体验同步，仍不保存所选原图。
- 新记录必传 1 张；旧多照片记录可原样保留附件并修改文字，更换照片时按新限制。历史版本和原照片不删除，已有授权、归属、24 小时期限及版本检查保留。
- 无 SQL 迁移：既有读取 RPC 的最多 3 个照片 ID 仍用于读取历史记录，写入数量由 V2 网关校验。V1 后端是历史回归资料，不作为本次发布入口。

验证：类型检查、225 项测试通过（43 项环境相关测试跳过）、20 个 WXML 编译及 V2 构建通过。覆盖恰好 2MB 上传、超出 1 字节拒绝、前端压缩后仍超限拒绝、第二张和空照片提交拒绝、旧多照片文字更正及历史保留、审核体验 2MB 路径。

交付时未部署或上传，未用真实照片测试。与信息部干事名单导出提交一同交由代码推送对话更新私有 main、既有 xueduTrial 和微信开发版；无需执行迁移或清理。发布后手机上传性能仍需实测，不能用本地桩测试替代。
