## 不照搬的旧行为与剩余差异

- V1 通过全量 snapshot 得到精确待审核总数、全学期个人任务总数以及跨全部资料搜索。现有 V2 接口没有这些专用汇总/搜索参数；本次按已加载范围展示，不扫描所有历史。精确汇总和全库搜索如需恢复，应另加兼容分页的服务端接口。
- V1 的普通成员全组条目、查看学期即改变组织启用学期、已记录周不可调整、删除全部管理员等旧行为不恢复，遵循现已确认的 V2 规则。
- 表单仍沿用 V2 通用字段布局，没有宣称所有页逐像素恢复。提交页的分组布局、快捷标记缺失/其余为零、照片缩略图预览，以及更多课程筛选维度仍可在后续前端工作中恢复；本次没有更改其提交字段、照片或缺失值语义。
- 不自行增加 Excel 适配、公告后台、新角色或自动确认排班。
