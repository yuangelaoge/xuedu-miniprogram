# 任务与安排表显示课表人数

## 范围和来源

在 1.3 发布记录提交 `43f3636` 上追加开发，分支 `codex/course-headcount`。

已核对 `SchoolClass` 类型与 V2 `classSave`：现有班级维护模型没有独立学生总人数字段。可用来源为任务课程快照里的 `course.expected`，语义是课表应到人数。此次统一标注“课表人数”，不把它说成行政班学生总数，也不读取学生花名册推算。

- 首页“我的本周任务”和听课安排“正式任务”显示课表人数，普通干事的本人任务同样显示。
- 一个任务含多门课程时，逐门列课程名称、日期/节次及各自人数，不能把默认课程人数套给全部课程。
- 合班显示该门课程合计，页面标注“合班合计”；不拆分或复制成各行政班人数。
- 数值 0 显示“0 人”，Excel 保存为数字 0；未知、缺失或无效值显示“未填写”。
- 独立听课安排表新增“课表人数”列，位于课程名称之后。身份/姓名合并不变，无课成员仍保留一行身份姓名，其余八列为空；一门合班课仍只占一行。
- 人数沿用原任务快照，已完成任务、旧单课程任务无需回填。现有听课记录的观察应到/实到、统计报表不修改，提交表单也不自动填写观察人数。
