## 实现

- 明确区分 canViewAllRecords、canExportFullXlsx、isManager、canGeneratePlan、canConfirmPlan、canAdjustTasks、canExportNames。未将干事加入管理人员。
- 服务端普通records/record/recordVersions、page-load列表/详情、私有photoUrls（含按ID及历史版本读取）同步准许干事。可信微信、有效成员、轮次、学期和权限变更校验仍保留；未提交照片仍只允许上传者读取。
- 全组记录使用独立分页列表，默认50、最多100；报表收集完目标周所有分页，不靠加载整份周数据。兼容week查询继续返回干事本人的任务/记录和无课资料；全组阅读走records/report。任何角色的availability返回都按当前服务端actor过滤，客户端memberId不能替换目标。
- 新版干事导出改用excelReport → exportXlsx → reportSheets，与管理员共享原始数据、公式、统计、原生可编辑图表及空周行为，不嵌入照片。summaryReport仍用于轻量统计和旧前端兼容。
- report(format=xlsx)及reportCheck(format=xlsx)准许管理员/干事；txt/copy和namesReport仍仅管理员。导出前后验证版本，直接调用前端handler也受约束。领域TXT/Excel导出器同步收紧角色，不恢复组部长导出。
- 记录页为干事提供“听课汇总”和全组列表，默认选中全组；详情可看照片、不可代改。审核会话复用同一gateway；本地demo的详情和Excel权限同步。
