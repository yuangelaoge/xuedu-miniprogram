# 学风督察小程序

## 角色权限

| 角色 | 主要权限 |
| --- | --- |
| 管理员 | 全部管理权限；维护班级、学期和课程；审核成员；生成、确认及调整排班；查看和导出全组资料。 |
| 组部长 | 审核申请、移除普通成员；查看全组记录、照片和统计。不能生成或确认排班草稿、调整任务或导出名单/完整 Excel。 |
| 信息部干事 | 查看全组记录、历史记录和签字照片；生成排班草稿；导出完整 Excel。不能确认草稿、调整任务、导出 TXT/复制名单、管理成员或查看他人的具体无课时段。 |
| 普通成员 | 填写本人无课时间、完成本人任务并查看本人记录。 |

排班和调整先生成草稿；当前权限下只有管理员能确认排班或任务调整。服务端按可信微信身份校验权限，不以客户端传入的角色为准。

## 架构与数据

页面 → `miniprogram/services/v2/` 客户端 → `server/v2/` 服务端 gateway/policy → `xueduTrial` → PostgreSQL 和私有照片存储。PostgreSQL 使用实体表和事务；列表默认分页 50 条、最多 100 条。打开页面或下拉刷新时同步数据，不提供实时推送；本机草稿不跨设备同步。

无课时间与听课记录按学期、周次保存。`0` 表示真实零，`-1` 表示缺失，缺失值不参与人数和比例计算。Excel 从业务数据生成统计和图表；导出前后核对数据版本。
