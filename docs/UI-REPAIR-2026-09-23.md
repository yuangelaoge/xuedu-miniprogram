# V2 前端布局回归修复

2026-09-23 用户指出三推后原有正常页面消失。检查确认：V2 分支使所有云端页面改用同一份简化 cloud.wxml，原页面 WXML 被放在 demo 分支；上次部署仅核验新开关，遗漏整页视觉验收。

本次保留 V2 协议和现有线上数据库：恢复首页原有问候、蓝色周次卡、无课时间入口、个人任务卡与全组进度；恢复“我的”资料卡和菜单；恢复排班、记录的周次导航和记录分页签、无课时间按星期/节次网格；管理入口和表单采用既有卡片及按钮样式，自动通过及截止时间表单继续保留。没有恢复旧版客户端整份快照写入方式。

验证：类型检查、134 项测试（9 项独立数据库测试本轮跳过）、14 个 WXML 编译通过；补充首页任务卡映射、时间格切换及所有拆分模板事件绑定验证。真实模拟器打开首页、听课安排、听课记录、我的、无课时间、课程总表、管理工作台，均无页面连接错误；自动通过开关仍可见。空学期下不能以这些截图宣称实际排班、照片、双微信、多设备已完整验收。截图保留在忽略目录 artifacts/ui-repair，不入 Git。

发布范围仅私有 GitHub 和微信开发版；不部署云函数、不迁移数据库、不写入线上业务、不设置体验版或提交审核、正式发布。恢复数据不属于本次界面修复。代码可从确认提交重新构建上传，不能单独回退到不兼容当前 V2 后端的旧 V1 客户端。
