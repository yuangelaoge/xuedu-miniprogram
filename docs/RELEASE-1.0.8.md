## 功能与权限

管理员可将有效成员设为信息部干事，仍需确认、原因和审计。信息部干事可查询按周分页的提交状态、生成排班草稿、查看及导出教学班汇总；没有他人原始记录、照片、无课时间详情、名单 TXT、排班确认或成员管理权限。本人任务、记录和照片沿用普通成员的归属规则。其听课参与方式与普通成员相同，管理员、部长仍按周自愿报名。

新增 `submissionStatus`、`summaryReport` 查询。名单只返回姓名、班级和提交状态，后者只返回教学班统计；分页及导出校验 workspace 版本。汇总中同班多次记录累计，合班计一次，跨年级合班单列，缺失与零分母不伪装为零出勤。Excel 统计页用来源公式、稳定排序及原生图表关系；全体班级迟到按人数，年级页按比例。管理员导出保留原始明细，干事导出不含个人原始字段。
