## 问题与修复

前序真机排查记录显示：同一手机的 V2 首页启动请求，`review: true` 返回 `INTERNAL_ERROR`，`review: false` 可正常读取首页。线上审核会话究竟已过期还是缺失，未直接查询；不能将本地合成验证写成线上数据库实测。

- `server/v2/review.ts` 导出审核构建包实际使用的 `BusinessError`。
- `cloudfunctions/xueduTrial/index.js` 同时识别正式包和审核包明确导出的可信错误类型。
- 未改为信任任意异常的 `code`、`name` 或原始 `message`；未知异常继续返回固定提示，数据库异常继续按现有安全映射返回。
- 审核会话有效期、可信微信校验、角色权限及与正式业务的隔离规则均未调整。

现有客户端在收到 `REVIEW_EXPIRED` 后会清除本机审核标记并重置会话。此次失败仍显示到期提示，用户再点一次首页重试即可发出正常模式请求；本次未新增自动重试。
