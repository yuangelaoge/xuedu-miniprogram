# 全组文字记录查看（2026-10-22）

用户已确认：所有有效已审核成员可查看听课汇总和记录文字（包括人数、请假/旷课名单、评价、反馈、建议及修改历史）；普通干事不能查看他人照片。本人照片、管理员/组部长/信息部干事既有照片权限保留，不增加普通干事的导出、编辑他人记录、周统计或管理权限。

本地实现：文字与照片能力分离，记录列表/详情/历史返回时移除无权限照片标识；照片接口对记录、历史版本和照片编号三种请求均校验权限。前端无照片权限时不请求图片链接、不显示图片或历史照片按钮，普通干事仍默认个人听课，可切到听课汇总。

现有数据库快速读取函数仍限制普通干事只能看本人记录，因此其 records 页面在可信身份返回后回退到现有网关分页查询；不修改数据库结构或函数，不执行迁移。管理员等现有快速路径保留。该兼容路径会增加数据库读取，不能把本次功能称为整体费用优化；减少的是查看他人照片的请求和流量。

验证：全套本地测试 268 通过、44 跳过；随后新增快速路径兼容测试，页面边界测试 26 通过。类型检查、18 个 WXML 编译与云函数本地构建通过。测试均为合成数据，未连接生产；未部署后端、未上传前端，未真机验收。上线需要前后端配套发布。
